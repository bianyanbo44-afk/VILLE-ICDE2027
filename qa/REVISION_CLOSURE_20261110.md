# VILLE 投稿前修订完成记录

| 项目 | 修订及证据 |
|---|---|
| ORDER BY 耗尽兜底 | 两组完全读完时立即用精确均值解析配对。三组小总体的全部 27 条排列路径均通过回归。 |
| Top-k 实际调用计费 | 缓存与实时执行使用共享状态机，候选选择只看已读前缀，组重新激活前的调用全部保留。原最小反例计为 3,100 次，与实时入口一致。 |
| 主实验 | 75 查询，每查询每方法 30 次，共 18,000 次缓存执行。VILLE 最终答案和使用的决定错误均为 0/2,250。 |
| 敏感性实验 | 五组共 61 个配置，每方法每配置 10 次，共 4,270 次缓存执行。VILLE 未出现答案或决定错误。 |
| 全执行历史核验 | 检查 22,270 次执行、7,755,931 轮。分组前缀单调、每轮增量最多 100、累计调用等于实际前缀之和，最终统计与摘要一致。 |

| 错误指标 | 最终答案错误与使用的决定错误分列。CLT 为 5/2,250 和 16/2,250，CLT+P 均为 3/2,250。最高最终答案错误率仍为 13% 和 7%。 |
| 方法叙事 | 按 Evergreen 的实际阈值早停机制修订比较，将收益归因限定为具体投注策略、直接成对构造和代理整合。区分受约束最优 beta、实际估计 beta 和理想方差等式。删除所有路径严格提前停止的表述。 |

主要数字为 Evergreen-CS/VILLE 调用数几何均值 2.33354，最大 8.24725，文中分别报告 2.3 倍和 8.2 倍。旧稿的平均优势舍入值仍为 2.3 倍，最大优势由 8.3 倍更新为 8.2 倍。敏感性文字已同步实际重跑数字，包括最强代理节省 35%、margin 减半增加 22%、加倍减少 23%。

执行记录同时保留了较早的完整决定历史格式和较后的增量决定格式，两者均记录每轮真实前缀及调用。少数记录的 `read_groups` 含已耗尽的活跃候选组，该组增量为零；计费核验使用实际前缀，而非活跃组数量。

复现包提供源代码、固定标签及代理分数、原种子、全部执行记录、图表脚本、最终论文源文件和 SHA256 文件清单。压缩数据与原数组逐项一致。proxy-sweep 包含实际研究使用的六个数组，原始文件中的其余三个 rating 代理数组未纳入本包。

本轮采用 anti-defensive-writing 和 nature-figure 的写作及绘图检查流程。更改提高了论述与证据的一致性，不构成录用保证。参考文献没有在本轮重新做逐条完整元数据认证。
