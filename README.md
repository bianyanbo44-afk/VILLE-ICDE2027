# VILLE reproducibility package

This package reconstructs the experiments in "VILLE: Certified Decision Queries over LLM-Evaluated Data with Proxy-Rectified E-Processes" from fixed model judgments and proxy scores.

Download the complete [submission package](https://github.com/bianyanbo44-afk/VILLE-ICDE2027/releases/tag/v2026.11.10) for the fixed labels, proxies and detailed execution records.

## Environment

The cached replay used Python 3.12.10, NumPy 2.5.4, SciPy 1.18.1 and scikit-learn 1.9.1. Install `requirements-cached.txt` in a dedicated environment. The separate graphics environment is recorded in `requirements-figures.txt`. PyMuPDF supports figure checks. Fresh model execution additionally uses PyTorch, Transformers and DuckDB. The corrected results record the NumPy version and original query seeds. The package manifest records file hashes.

## Main comparisons

Run these commands from the package root. Each query uses the original sampling seeds and 30 independent permutations. The output folder must be different from the supplied results so that an existing result does not skip a requested recomputation.

```sh
python -I semdec/test_query_schedule.py
python -I semdec/replay_saved.py stars data results/d1_main.json reproduced/d1_main.json
python -I semdec/replay_saved.py llm data results/d2_wor.json reproduced/d2_wor.json
python -I semdec/replay_saved.py arxiv data results/d3_arxiv.json reproduced/d3_arxiv.json
```

The shared `DecisionState` drives cached replay and live requests. It uses each group's actual observed prefix for candidate selection, counts all reads across pauses and reactivation, and resolves exhausted pairs from exact means. Precomputing a certificate event on a fixed stream does not expose it to the scheduler before that stream has actually been read through the event's horizon.

Each query summary records the sampling seed and points to records containing the method, repetition, actual calls, per-group prefix lengths, returned answer, and round history. Some early trails store accumulated pair decisions; later trails store newly resolved decisions. In both formats the prefix lengths and cumulative calls describe the actual observed history. `read_groups` lists scheduled active groups and can include an exhausted group that adds zero calls. `answer_err` checks the final returned result against the paper's definition. `decision_err` separately checks the group or pair decisions used by that result. `err` retains their union for compatibility.

## Sensitivity studies

Each sensitivity query uses ten permutations. The supplied proxy-sweep file contains the three negative-review proxy score arrays and their cross-validated coefficients used by these studies.

```sh
python -I semdec/exp_ablation.py data/sem1_amazon.npz data/proxy_sweep.npz reproduced/abl_proxy.json 10 proxy
python -I semdec/exp_ablation.py data/sem1_amazon.npz - reproduced/abl_bad.json 10 bad
python -I semdec/exp_ablation.py data/sem1_amazon.npz - reproduced/abl_margin.json 10 margin
python -I semdec/exp_ablation.py data/sem1_amazon.npz - reproduced/abl_alpha.json 10 alpha
python -I semdec/exp_ablation.py data/sem1_amazon.npz - reproduced/abl_groups.json 10 groups
```

## Data and live execution

`data/sem1_amazon.npz` contains the star-derived attributes, group metadata and proxy scores for AMZ-Stars. `data/amz_llm` and `data/arxiv_llm` contain the fixed LLM judgments, group metadata and proxies. The original review text and abstracts can be reconstructed using the public data sources documented in `semdec/README.md` and the protocol files.

The archived live measurements use Qwen2.5-1.5B-Instruct and SmolLM2-1.7B-Instruct on a resident RTX 4060 laptop GPU. Each method/query has one measured execution. Its exact scan is a shared measured reference for the three queries over that model's predicate. Proxy preparation is recorded separately. The corrected cached scheduler was also checked against all 12 stored live method/query records, matching the answers, per-group prefixes and calls.

See `ONLINE_SYSTEMS_PROTOCOL_20261109.md` and `semdec/online_benchmark.py` for fresh model execution. A fresh output directory is required to obtain new timing measurements.

## Verification and manuscript

`python -I verify_execution_records.py results execution_integrity_recheck.json` checks all supplied main and sensitivity execution records. The supplied audit covers 22,270 executions and 7,755,931 rounds, including 18,000 main-comparison executions. These are cached reads, not fresh model requests. The stored live timings are the independently measured runs described above.

`manuscript/main.pdf` is the revised paper. The adjacent TeX, bibliography, tables and vector figures build with a standard IEEEtran/LaTeX installation using `latexmk -pdf main.tex` from `manuscript/`. The fixed submission release is [https://github.com/bianyanbo44-afk/VILLE-ICDE2027/releases/tag/v2026.11.10](https://github.com/bianyanbo44-afk/VILLE-ICDE2027/releases/tag/v2026.11.10). Download the attached reproducibility ZIP for the data and full execution records. The Git source snapshot supplies code, manuscript sources and compact summaries.
